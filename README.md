# Pinefold

A first-person forest-work game built with React, TypeScript, Three.js, and Vite/TanStack Start.

## Run it

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

The game starts at the Home screen. Walk the woods, chop trees, carry logs to the yard, sell timber, and reinvest earnings into tools and helpers.
