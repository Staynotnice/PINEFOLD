# Pinefold

**Pinefold** is a small first-person 3D woodland work game. Chop trees, pick up logs, carry them to the yard, sell timber, and reinvest your coins into a growing forest camp.

## Run locally

Install [Node.js 22 or newer](https://nodejs.org/), then run:

```bash
npm install
npm run dev
```

Open the local URL printed by Vite.

## Controls

- **WASD / arrow keys** — move
- **Space** — chop nearby trees
- **Camp** — buy tools, a bigger pack, helpers, and camp upgrades
- **Escape / Pause** — pause the game

On touch screens, use the on-screen movement stick and **Chop** button.

## Build for production

```bash
npm run typecheck
npm run build
npm run preview
```

Progress saves in the browser. Keep using the same browser and device to continue that save.
